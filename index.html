📌 Cara Upload ke Google Drive:
  1. Buka Google Drive
  2. Klik "New" → "File upload"
  3. Pilih file PDF manual book
  4. Setelah upload selesai, klik kanan file → "Get link"
  5. Setel menjadi "Anyone with the link can view"
  6. Copy link-nya, lalu paste di bawah
Pastikan link sudah dishare ke "Anyone with the link can view"
